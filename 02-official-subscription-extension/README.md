# 第二版：机场官方订阅 + 完整扩展

本版本不包含节点，不读取私人订阅地址。机场官方远程订阅提供并更新节点；本扩展接管 DNS、策略组和分流规则。

## 使用

1. 在 Clash Verge Rev 中导入并激活机场官方远程订阅。
2. 确认官方节点能够正常测速和联网。
3. 下载 [Clash-Verge-Full-Extension.yaml](./Clash-Verge-Full-Extension.yaml) 和 [Clash-Verge-Replace-Routing.js](./Clash-Verge-Replace-Routing.js)。打开文件页面后点击 Raw，保存文件或复制全文。
4. 打开机场订阅卡片的右键或三点菜单。
5. 进入“扩展覆写配置 / 订阅扩展配置”，导入该文件或粘贴全部内容。
6. 进入同一订阅的“扩展脚本”，导入或粘贴 `Clash-Verge-Replace-Routing.js`。若编辑器已经有默认的 `function main(...)`，用下载脚本的全部内容替换编辑器全文，不要粘贴到原函数内部。
7. 保存后重新激活机场订阅。

扩展通过 `include-all` 自动读取官方订阅中的节点，因此官方更新或增减节点后无需修改扩展。

## 为什么还需要扩展脚本

部分 Clash Verge Rev 版本会把 YAML 扩展中的策略组和规则放在机场原有内容前面，而不是彻底替换数组。结果是节点能正常使用，但代理页面会同时出现两套策略组，运行配置也会保留机场的数千条规则。

订阅扩展脚本在 YAML 扩展之后运行，执行以下最终清理：

- 保留机场订阅中的 `proxies` 节点；
- 只保留本模板的 22 个策略组；
- 只保留本模板的 43 个规则提供器；
- 将 `rules` 强制替换为本模板的 89 条规则；
- 恢复最终规则 `MATCH,🏁 FINAL`；
- 删除不再使用的机场 `sub-rules`。

不要把脚本设置成“全局扩展脚本”，应绑定在同一个机场订阅的“订阅扩展脚本”位置。

已经使用旧版 YAML 扩展的用户：保留原 YAML 绑定，只增加这个订阅扩展脚本，然后重新激活。脚本没有网络或文件读取操作，运行时使用已经合并的配置。

重新激活后，在“查看运行配置”中确认：

- `proxies` 数量仍与机场订阅一致；
- `proxy-groups` 为 22 个；
- `rules` 为 89 条；
- 最后一条规则为 `MATCH,🏁 FINAL`；
- 不再出现机场的 `Proxies`、`YouTube`、`Disney`、`Final`、`HK`、`JP` 等策略组。

上述数量对应当前发布版本，今后模板更新可能改变数量。这里的 89 条是顶层路由规则；43 个远程规则集内部仍然可以包含大量域名/IP，不代表分流覆盖范围只有 89 个网站。

## 订阅与模板更新

- 机场节点更新：在官方订阅卡片点击“更新”，随后重新激活。无需手动复制节点。
- 机场订阅地址重置：在官方订阅卡片的“编辑信息”中更换 URL。保持两个扩展都绑定到该订阅。
- 本仓库模板更新：同时下载新版 YAML 与 JS，分别替换两个编辑器的全文，再重新激活。粘贴到编辑器的内容不会自动跟随 GitHub 更新。

## 常见问题与恢复

- 仍出现两套策略组：确认 JS 位于当前启用订阅的“扩展脚本”，已保存且已经重新激活；查看脚本日志是否有错误。
- 提示 `Routing replacement requires Clash-Verge-Full-Extension.yaml`：配套 YAML 没有正确绑定，或 YAML/JS 版本不配套。先重新粘贴 YAML，再重新粘贴 JS。
- 官方订阅本身测速失败：先单独测试官方订阅。此脚本只处理分流，不修复节点认证、订阅地址或网络连通性问题。
- 保存失败或无法联网：先备份当前两个编辑器的内容，再将订阅扩展脚本暂时恢复为 `function main(config, profileName) { return config; }`，重新激活。需要恢复纯官方配置时，再把订阅扩展配置恢复为空配置 `{}`。官方远程订阅和地址继续保留。
- 视频通话异常：可以把“STUN 防护”策略组选为 `PASS`；这会关闭该组对应的 STUN 阻断。

脚本依赖本模板的策略组名称。如果手动改名，需要同步修改 JS 中的名称和规则。当前脚本保留官方 `proxies`，也保留官方可能使用的 `proxy-providers`；机场节点若通过依赖旧策略组的 `dialer-proxy` 等链式连接工作，清理策略组后需要另行适配。本用户已验证的官方节点为内联节点。

本地验证已确认脚本在模拟合并输入中保留 90 个节点并输出 22 个策略组、43 个规则提供器、89 条规则。安装后仍需检查实际运行配置和联网；该结果不是对所有机场或所有软件版本的保证。

执行顺序及脚本语法参考：[Clash Verge Rev 官方脚本文档](https://github.com/clash-verge-rev/clash-verge-rev.github.io/blob/main/docs/guide/script.md)。

## Clash Verge Rev 设置

- TUN：开启
- TUN 堆栈：`Mixed`
- 自动设置全局路由：开启
- 严格路由：开启
- 自动选择流量出口接口：开启
- DNS 劫持：`any:53,tcp://any:53`
- MTU：`1500`
- IPv6：关闭
- DNS 覆写：关闭
- 运行模式：`Rule / 规则`

机场重置订阅地址后，只修改官方订阅卡片中的订阅 URL；扩展无需改动。

更完整的步骤和检查方法请阅读仓库根目录 README。
